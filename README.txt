# Raíz Chinampera — Maqueta web accesible

Abre `index.html` en un navegador para visualizar el sitio.

## Publicarlo para que cualquiera pueda verlo
1. Crea un repositorio público en GitHub.
2. Sube `index.html`.
3. En **Settings > Pages**, selecciona la rama principal y la carpeta raíz.
4. GitHub generará una dirección pública para el sitio.

## POUR aplicado
- Perceptible: estructura semántica, texto legible, contraste configurable y contenido no dependiente solo del color.
- Operable: navegación por teclado, enlace “Saltar al contenido”, foco visible y controles accesibles.
- Comprensible: lenguaje directo, navegación consistente y formularios etiquetados.
- Robusto: HTML semántico y compatibilidad con tecnologías de asistencia.

El contenido de negocio se basa en la presentación académica de Raíz Chinampera.
